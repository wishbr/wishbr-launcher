# Launcher do Wish BR

Launcher oficial do **Wish BR**, servidor brasileiro de roleplay no HogwartsMP.

## Baixar

**[Baixar o launcher (Windows)](https://github.com/wishbr/wishbr-launcher/releases/latest/download/WishBR-Setup.exe)**

Depois de instalado, o launcher se atualiza sozinho: não precisa baixar de novo.

## Antes de instalar

- Você precisa do **Hogwarts Legacy** (Steam ou Epic) e do **launcher oficial do HogwartsMP**, baixado no
  Discord oficial do HogwartsMP e aberto pelo menos uma vez.
- O Windows pode mostrar **"O Windows protegeu o computador"**, porque o instalador ainda não tem
  assinatura de código. Clique em **Mais informações** e depois em **Executar assim mesmo**.
- Cada versão tem o SHA-256 do instalador na página da release, para conferir o arquivo.
